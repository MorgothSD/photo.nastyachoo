# Цели в Яндекс.Метрике — счётчик 111770285

Метрика → Настройка → вкладка **Цели** → **Добавить цель**
→ тип **Целевое событие** → «Идентификатор цели» = **Совпадает** + значение из таблицы.

⚠️ **Поле «Название цели» обязательное.** Если оставить пустым — кнопка
«Добавить цель» останется серой. Название видите только вы в отчётах,
идентификатор — это то, что приходит с сайта.

## 2. Диагностика мессенджера — отвечает на вопрос «почему не пишут»

| Идентификатор | Название цели | Что означает |
|---|---|---|
| `messenger_bounce` | Мессенджер — ушёл сразу | Вернулся на сайт быстрее 8 секунд. Почти наверняка **не написал** |
| `messenger_short` | Мессенджер — 8–40 секунд | Возможно, написал коротко или передумал |
| `messenger_engaged` | Мессенджер — дольше 40 секунд | Скорее всего, написал |

**Как читать.** Если `messenger_bounce` окажется больше половины всех
кликов по мессенджерам — проблема в самом переходе, а не в сайте.
Тогда правильное решение — сделать форму главным действием,
а мессенджеры оставить дополнительным.

## Что считать бизнес-конверсией

**Да:** `form_submit`, `telegram_click`, `whatsapp_click`

**Нет:** `portfolio_view`, `packages_view`, `contact_view`, `quickbar_shown` —
это диагностика. Просмотр блока не является намерением купить.
Не оптимизируйте рекламу под них.

## Проверка

1. Откройте сайт в инкогнито
2. Нажмите Telegram → сразу вернитесь на вкладку
3. Через 5–15 минут в отчёте **Конверсии** должна появиться
   цель «Мессенджер — ушёл сразу»

Либо: DevTools → вкладка Network → фильтр `mc.yandex` —
при каждом действии должен уходить запрос на `mc.yandex.ru/watch/111770285`.

## Действия в рекламном кабинете

**1. Включить Яндекс Карты** — сейчас отключены. Это самый горячий источник:
человек ищет «фотограф рядом» и уже готов заказывать. Одно действие
в кабинете, важнее любых правок на сайте.

**2. Заменить тексты объявлений** — все четыре машинно-сгенерированы:

| Направление | Заменить на |
|---|---|
| Детский праздник | Фотограф на детский праздник. Снимаю репортажем: дети играют, я ловлю момент. Фото за 7–10 дней |
| Индивидуальная | Индивидуальная фотосессия в Москве. Позировать не нужно — подскажу, куда встать. От 3 500 ₽ |
| Мероприятие | Фотограф на мероприятие. Незаметный репортаж, гости не позируют. Обсудим дату |
| Свадьба | Свадебный фотограф в Москве. От сборов до танцев. Живые кадры без постановки |

**3. Не использовать картинки от нейросети**, которые предлагает Яндекс.
Для фотографа это прямой удар по доверию. Для свадебного объявления
используйте `wedding-4.webp` — поцелуй с букетом роз.

**4. UTM-метки и deep links** для разделения направлений:

```

https://photo-nastyachoo.ru/#children?utm_source=yandex_business&utm_medium=cpc&utm_campaign=children
https://photo-nastyachoo.ru/#individual?utm_source=yandex_business&utm_medium=cpc&utm_campaign=individual
https://photo-nastyachoo.ru/#studio?utm_source=yandex_business&utm_medium=cpc&utm_campaign=studio
https://photo-nastyachoo.ru/#events?utm_source=yandex_business&utm_medium=cpc&utm_campaign=events
```

Человек по свадебному объявлению сразу увидит свадебные работы —
галерея откроется с уже применённым фильтром.
