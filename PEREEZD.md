# Переезд на reg.ru: что делать с формой

## Что ломается

Сейчас форма отправляет данные на `/` — это механизм **Netlify Forms**.
На обычном хостинге такого механизма нет: запрос упрётся в 404.

Раньше ошибка проглатывалась молча — человек видел «Записала ваш номер»,
а заявка исчезала. Теперь при сбое он увидит честное «Не удалось отправить»
и кнопку «Скопировать текст заявки», а в Метрику уйдёт цель `form_failed`.

---

## Шаги переезда

### 1. Создать почтовый ящик на домене

Панель reg.ru → Почта → создать ящик вида `noreply@photo-nastyachoo.ru`.

Это обязательно. Если письма будут уходить с чужого адреса, почтовые
сервисы отправят их в спам или отклонят.

### 2. Настроить send.php

Откройте файл и замените две строки вверху:

```php
const MAIL_TO   = 'ваша-почта@example.com';       // куда слать заявки
const MAIL_FROM = 'noreply@photo-nastyachoo.ru';  // созданный ящик
```

### 3. Переключить форму на PHP

В `index.html` найдите строку:

```javascript
var FORM_ENDPOINT = '/';
```

замените на:

```javascript
var FORM_ENDPOINT = '/send.php';
```

Это единственная правка в HTML.

### 4. Залить файлы на хостинг

В корень сайта (обычно `public_html` или `www`):

```
index.html
privacy.html
send.php
images/
```

### 5. Закрыть доступ к файлу с заявками

Скрипт пишет резервную копию каждой заявки в `leads.csv`.
Чтобы его нельзя было скачать из браузера, создайте в корне
файл `.htaccess`:

```apache
<Files "leads.csv">
  Require all denied
</Files>
```

### 6. Проверить

Заполните форму с телефона реальными данными.
Должно произойти три вещи:

- на экране появится «Записала ваш номер» с галочкой
- письмо придёт на почту из `MAIL_TO`
- в файле `leads.csv` появится строка

Если письма нет, а строка в CSV есть — проблема в почте,
проверьте ящик `MAIL_FROM` и папку «Спам».

---

## Что умеет send.php

| Функция | Зачем |
|---|---|
| Проверка honeypot | Отсекает ботов, заполняющих скрытое поле |
| Ограничение 30 секунд на IP | Защита от массовой отправки |
| Очистка переводов строк | Защита от подстановки почтовых заголовков |
| Проверка имени, телефона и согласия | Дублирует проверку на стороне сайта |
| Запись в `leads.csv` | Заявка не теряется, даже если почта не работает |
| BOM в начале CSV | Excel корректно открывает кириллицу |
| Ответ в формате JSON | Сайт понимает, сохранилось или нет |

---

## Новая цель в Метрике

| Идентификатор | Название |
|---|---|
| `form_failed` | Заявка не отправилась |

Если начнёт срабатывать — значит обработчик недоступен,
и заявки теряются. Это сигнал проверить хостинг немедленно.
